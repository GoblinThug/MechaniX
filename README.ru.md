# MechaniX

[![Paper](https://img.shields.io/badge/Paper-1.21.1+-blue.svg)](https://papermc.io)
[![Folia](https://img.shields.io/badge/Folia-supported-brightgreen.svg)](https://papermc.io/software/folia)
[![Java](https://img.shields.io/badge/Java-21-orange.svg)](https://adoptium.net)

Плагин для Paper/Folia, добавляющий **механические ворота** и **порталы телепортации**, построенные из обычных блоков Minecraft — без ресурспаков, клиентских модов и NMS.

Собери рамку из заборов, стенок или железных прутьев, нажми на кнопку — и стена поедет в сторону. Или свяжи две рамки порталом и просто пройди сквозь.

**🌐 [English version](README.md)**

---

## Возможности

### Ворота
- Определяются автоматически при ПКМ по рамке инструментом привязки.
- Открываются кнопками, рычагами, нажимными плитами и редстоуном.
- Направление открытия настраивается: `BOTTOM_UP`, `TOP_DOWN`, `X_AXIS`, `Z_AXIS`.
- Блоки двигаются пошагово с настраиваемой задержкой (по умолчанию 4 тика) — даже большие ворота открываются плавно.
- Кулдаун на клик для защиты от спама.
- Опциональные звуки открытия/закрытия.
- Открытые ворота восстанавливаются после рестарта сервера.
- Лимит зон на игрока (обходится с `mechanix.admin`).

### Порталы
- Две связанные рамки — мгновенная телепортация между ними.
- Работают **между мирами** (Обычный ↔ Нижний ↔ Край и т.д.).
- Поддерживаются вертикальные, горизонтальные и потолочные рамки.
- Опциональная визуализация — анимированная рамка из частиц с «дышащей» заливкой.
- Свой цвет (hex) для каждой рамки при использовании частиц `DUST`.
- Кулдаун телепортации — защита от зацикливания.
- Система владения — игроки управляют своими порталами.
- Полноценное GUI (`/portal`) для создания, просмотра и удаления порталов.

### Общее
- Всё через GUI (`/mx`, `/portal`) — не нужно запоминать команды.
- Обратная связь в actionbar или в чат (настраивается).
- Гибкие права (совместимо с LuckPerms).
- Редактируемые сообщения в `lang/ru.yml` и `lang/en.yml`.
- **Готов к Folia**: все планировщики учитывают регионы при запуске на Folia.

## Требования

| Компонент | Версия |
|---|---|
| Сервер | **Paper 1.21.1+** или **Folia 1.21.1+** |
| Java | **21** |

> **Spigot/CraftBukkit не поддерживаются.** Плагин использует Paper-only API: `Player#teleportAsync`, Adventure и т.д.

## Установка

1. Скачай последний `MechaniX-x.y.z.jar` из [Releases](../../releases).
2. Положи его в папку `plugins/` сервера.
3. Перезапусти сервер.
4. Настрой `plugins/MechaniX/config.yml` под себя.
5. Выполни `/mx reload` в игре, чтобы применить изменения.

## Быстрый старт

### Создание ворот

1. Собери рамку из заборов, стенок или железных прутьев — всё, что перечислено в `gates.allowed-blocks`.
2. Поставь рядом кнопку, рычаг или нажимную плиту.
3. Выполни `/mx`, выбери **Создать ворота** и следуй подсказкам, чтобы выбрать область.
4. Привяжи ворота к триггеру — нажми на триггер, когда попросит.
5. Готово. ПКМ по триггеру — открыть/закрыть.

### Создание портала

1. Построй **две** рамки из любых сплошных непрозрачных блоков (камень, дерево и т.п.).
   - Обе рамки должны быть **полностью замкнуты** (сплошное кольцо вокруг пустой внутренней области).
   - Минимальный внутренний размер: `portals.min-side` (по умолчанию 2×2).
   - Максимальный внутренний размер: `portals.max-side` (по умолчанию 21×21).
2. Выполни `/portal` и выбери **Создать портал**.
3. Кликни внутри рамки A, затем внутри рамки B.
4. Введи имя и hex-цвет (`#RRGGBB`) в чате.
5. Пройди через любую рамку — телепорт в другую.

> Установи `portals.allow-horizontal: false` в `config.yml`, чтобы запретить лежачие порталы и оставить только вертикальные.

## Команды

| Команда | Алиасы | Право | Описание |
|---|---|---|---|
| `/mx` | `/mechanix` | `mechanix.menu` | Открыть главное меню |
| `/mx reload` | | `mechanix.admin` | Перезагрузить конфиг |
| `/portal` | `/portals` | `mechanix.portal.use` | Открыть меню порталов |

---

## Права

| Право | По умолчанию | Описание |
|---|---|---|
| `mechanix.menu` | `true` | Доступ к главному меню |
| `mechanix.use` | `true` | Использование ворот |
| `mechanix.create` | `op` | Создание ворот |
| `mechanix.bind` | `op` | Привязка ворот к триггерам |
| `mechanix.delete` | `op` | Удаление ворот |
| `mechanix.portal.use` | `true` | Использование порталов |
| `mechanix.portal.create` | `op` | Создание порталов |
| `mechanix.portal.delete` | `op` | Удаление порталов |
| `mechanix.admin` | `op` | Обход всех проверок и лимитов |

Проверку прав можно отключить целиком через `permissions.enabled: false` в `config.yml`.

## Конфигурация

Полный конфиг с комментариями — в [`config.yml`](src/main/resources/config.yml). Основное:

```yaml
gates:
  step-delay-ticks: 4          # Задержка между шагами открытия (тики)
  open-direction: BOTTOM_UP    # BOTTOM_UP, TOP_DOWN, X_AXIS, Z_AXIS
  click-cooldown-ms: 500       # Защита от спама кнопки
  max-zone-volume: 20000       # Защита от краша

portals:
  allow-horizontal: false      # Запретить лежачие порталы
  cooldown-ms: 2000            # Кулдаун телепортации на игрока
  min-side: 2
  max-side: 21
  show-active-borders: true
  active-border-period: 2      # Меньше = плавнее поток частиц
  particles:
    fill-enabled: true
    fill-step: 1.0
    border-density: 1
    fill-density: 1
    drift: 0.25
    spread: 0.1
```

## Локализация

Языковые файлы лежат в `src/main/resources/lang/`. По умолчанию два:

- `ru.yml` — русский
- `en.yml` — английский

Чтобы добавить язык, скопируй `en.yml`, переведи значения и укажи `general.locale` = имя файла без расширения.

## Совместимость

- **Paper 1.20.6 и ниже**: `Registry.SOUNDS` ещё не существует — плагин рассчитан на **1.21+**.
- **Spigot / CraftBukkit**: **не поддерживаются** — код использует Paper-only API.
- **Folia**: поддерживается. Вся работа с регионами идёт через `MechaniX#runTaskAt` / `runTaskAtLater`, которые автоматически переключаются на region-планировщик при обнаружении Folia.
- **Гибриды (Mohist, Arclight)**: не тестировалось. Paper API эмулируется частично, возможны шероховатости.

---

## Известные ограничения

- Порталам нужна **полностью замкнутая рамка**. Открытые арки не поддерживаются — алгоритм ищет замкнутую воздушную область.
- Портал не может пересекаться с внутренней областью другого портала.
- Нет внутриигрового редактора существующих порталов — удали и создай заново, если нужно поменять рамку.
